# CareerAI India - Simple Version
## Only 3 files needed: server.js + public/index.html + .env

---

## STEP 1 - Install packages
Open terminal in VS Code (Ctrl + `) and run:
```
npm install
```

## STEP 2 - Create .env file
- Copy .env.example
- Rename copy to .env
- Replace your_key_here with your Anthropic API key
- Get free key at: https://console.anthropic.com

Your .env should look like:
```
ANTHROPIC_API_KEY=sk-ant-api03-xxxxxxxxxx
```

## STEP 3 - Run the app
```
npm start
```

## STEP 4 - Open browser
Go to: http://localhost:3000

That's it! ✅
